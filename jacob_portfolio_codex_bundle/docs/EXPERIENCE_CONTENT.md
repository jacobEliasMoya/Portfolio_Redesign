## Interaction Direction — Experience Accordion

Experience uses four substantial horizontal pill/accordion rows, following the same interaction grammar as What I Build without becoming a full résumé.

- Preserve one row for each career step in chronological order: VAREP, BizIQ Web Developer I, BizIQ Web Developer II, and Innervi.
- Each collapsed row shows its number, employer, title, dates, a restrained supporting 3D object, and a circular expansion control.
- Expanded content may reveal the concise homepage summary while keeping the full résumé as the destination for deeper detail.
- Use semantic buttons and regions, keyboard navigation, visible focus states, and reduced-motion behavior.
- Mobile stacks the same rows vertically; it does not require a separate carousel fallback.
- Keep text as ordinary semantic HTML.
- Place the section on a cool powder-blue/lavender background field so it remains visibly distinct from the warm page canvas.
- On desktop, Experience begins as the active panel inside a shared pinned stage. Continued vertical scrolling translates the complete Experience panel left while What I Build enters from the right. Both panels retain their accordion layout and are clipped by the shared viewport during the handoff.

The earlier prism and front-facing carousel/Rolodex remain documented explorations only and are not implementation references for the homepage.
