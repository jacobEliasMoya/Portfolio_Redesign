# Prompt — Mobile Adaptation

Adapt the approved portfolio design for mobile without simply shrinking the desktop layout.

Preserve:

- bold hero typography
- pastel/3D identity
- strong project imagery
- thick capability shapes
- Lab pastel field
- coral footer
- generous section separation

Change interaction where necessary:

- What I Build should not use the long desktop sticky-scroll interaction.
- Render capability pills as large touch-friendly expandable panels.
- Tapping reveals contextual technology/copy.
- Prefer one active panel if multiple expanded panels make the page unwieldy.

Selected Work may become a swipeable horizontal sequence or intentional vertical stack, but do not squeeze multiple desktop cards side-by-side.

Test small screens, text wrapping, orientation changes, keyboard/focus behavior where relevant, touch targets, and reduced motion.
