# Prompt — Selected Work and Project Detail

Preserve Selected Work as a high-art-direction showcase rather than converting it into a generic card grid.

Homepage behavior:

- large project presentation
- partial next-project visibility when appropriate
- restrained hover/focus response
- project title and essential metadata remain legible
- each project is a normal accessible link

Project details should provide the engineering proof the homepage intentionally omits.

Create a reusable case-study structure capable of presenting:

- Problem
- Role
- Constraints
- System / architecture
- Key decisions
- Design/product exploration
- Implementation
- Technology
- Result / outcome
- Screenshots/media
- repository/demo links where appropriate

Do not force every project to have identical internal art direction. Share typography/tokens/layout primitives, but let individual projects vary compositionally.
