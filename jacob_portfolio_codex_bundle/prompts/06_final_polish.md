# Prompt — Final Interaction and Quality Pass

The static/responsive design and functional interactions should already be complete before starting this pass.

Add only motion that reinforces the existing design:

- capability expansion transitions
- subtle project hover/focus response
- restrained 3D/parallax response where it remains performant
- purposeful route/section transitions

Then run a quality pass:

- `prefers-reduced-motion`
- keyboard navigation
- focus visibility
- semantic landmarks/headings
- accessible interactive names/states
- mobile touch targets
- image optimization
- loading behavior
- LCP/CLS/performance
- hydration/client-JS minimization
- no interaction required for critical content discovery

Delete effects that feel ornamental, generic, or slow the experience.

Final visual test: the site should still read as the same design shown in `images/approved/`, not as a framework/component-library reinterpretation of it.
