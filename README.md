# Portfolio_Redesign

Monorepo for Jacob Moya's portfolio, a future Payload CMS application, and custom Go services.

## Structure

- `apps/web` — Next.js portfolio
- `apps/cms` — reserved for Payload CMS
- `services/go` — reserved for custom Go services
- `packages` — shared packages and configuration

## Development

Install dependencies from the repository root, then start the web application:

```bash
npm install
npm run dev
```
