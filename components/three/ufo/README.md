# Classic UFO

Original procedural saucer model in `components/three/ufo/`, matching the scene's chunky beveled polygon language.

## Model

- Broad closed 24-faceted disc, radius 2.23 local units, with a shallow raised center and layered dark rim.
- Large silver/graphite hexagonal top and underside plates, using the same beveled prism construction as Earth and Moon. No tiny surface tiles.
- Twelve-facet smoked-cyan canopy, six silver cockpit ribs, visible seat, dark cockpit floor and hexagonal crown.
- Twelve inset cyan navigation lights, underside engine ring, recessed hexagonal aperture and three vent pods. No weapons or beam effect.
- Shared instanced geometry for plating, lights and housings. Merged frame-rib mesh. No external runtime model or texture dependency.
- ClassicUFO accepts position, rotation, scale, hover and reducedMotion. Subtle idle bob/roll can be disabled; reduced motion keeps it still. Geometry is disposed on unmount.
- Inspect `/ufo` in three-quarter, side, top and underside views with orbit/zoom controls. The UFO is not placed into the Earth scene yet; flight path and interactions are a subsequent design decision.
